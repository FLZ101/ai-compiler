# `@triton.jit` and its relationship to `torch.compile`

## What `@triton.jit` means

`@triton.jit` marks a Python function as Triton GPU source, not as a normal
Python function.

- Triton parses and compiles the function body into GPU code on the first
  launch.
- The function becomes a `JITFunction`; it is launched as
  `kernel[grid](args...)`, not called like a Python function.
- Parameters annotated `tl.constexpr` are resolved at compile time, so Triton
  can specialize block sizes and unroll loops.
- The compiled kernel is cached, so later launches reuse the same GPU binary.
- Python control flow inside the body is traced and lowered to Triton IR rather
  than executed by the Python interpreter.

In `triton_handwritten.py`, `@triton.jit` makes `matmul_kernel` a Triton
kernel. Its `BLOCK_M`, `BLOCK_N`, and `BLOCK_K` parameters are `tl.constexpr`
values supplied by the host launch.

## How it relates to `torch.compile`

`@triton.jit` is the low-level manual mechanism. `torch.compile` uses Triton
automatically as its GPU backend.

```text
PyTorch eager
  -> Dynamo
  -> FX graph
  -> AOTAutograd
  -> TorchInductor
  -> generated Triton source
  -> @triton.jit / Triton compiler
  -> GPU kernel
```

- `torch.compile` traces Python into an FX graph, runs AOTAutograd, and passes
  the graph to TorchInductor.
- Inductor's Triton backend generates kernel source as a string, decorates it
  with Triton wrappers, then compiles and launches it.
- The generated kernel uses the same `tl.program_id`, `tl.arange`,
  `tl.range`, `tl.dot`, and `tl.store` primitives as the hand-written kernel.

In the Task 08 output log, Inductor emits:

```text
@triton_heuristics.reduction(
    ...
)
@triton.jit
def triton_red_fused_mm_0(...):
    ...
    tmp8 = tl.dot(tmp6, tmp7, input_precision="ieee")
```

The extra `@triton_heuristics.reduction` wrapper is Inductor machinery for
autotuning, block-size selection, warps/stages, and launcher metadata. The
actual GPU function is still a Triton `@triton.jit` kernel.

## Key difference

| | `@triton.jit` | `torch.compile` |
| --- | --- | --- |
| Programming model | explicit kernel code | normal PyTorch code |
| Grid/pointers/masks | written by hand | generated by Inductor |
| Block sizes/warps | supplied by the author | selected or autotuned by Inductor |
| Compilation scope | one Triton function | whole traced graph |
| Usage | `kernel[grid](...)` | `compiled_fn(...)` |

`@triton.jit` is the primitive that makes TorchInductor's Triton codegen
runnable on the GPU.
